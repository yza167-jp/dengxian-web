# 《登仙台》网页版

本仓库基于 [XLT-6/mofa-dengxiantai](https://github.com/XLT-6/mofa-dengxiantai) 开展网页版游玩开发：目标是在电脑浏览器中提供可单机游玩的《登仙台》体验，并支持由大模型或本地启发式 bot 驱动的 AI 座位。

当前项目的开发基线与验收要求见 [构建规格](./dengxiantai-web-build-spec.md)。实现开始前会先以原仓库中的规则材料为准完成规则抽取；本仓库的具体实现不应凭空补写规则。

## 开发方向

- 中文界面的单机浏览器版桌游体验；
- 一名真人玩家与多个 AI 座位同局游玩；
- 客户端持有可测试的确定性规则引擎，后端仅代理大模型决策；
- 无 API key 时可用本地 bot 完成离线游玩与自动模拟。
